# ⚽ FC 매니저 시스템 — 주요 기능
## 1. 📊 대시보드
통계 요약 — 총 선수, 활동 선수, 경기 수, 포지션 현황
다가오는 경기 — 일정별 정렬, 배정 선수 수 표시
활동 선수 목록 — 카드 형태로 한눈에 확인
## 2. 👥 선수 관리
기능	설명
선수 등록	이름, 등번호, 포지션, 나이, 신장, 체중, 국적, 상태(활동/부상/은퇴), 메모
선수 목록	검색 필터, 표 형태 목록, 상태별 뱃지 표시
선수 상세	프로필 카드, 전체 정보, 수정/삭제
CRUD	등록 · 수정 · 삭제 · 목록 이동
## 3. 📅 경기 일정
경기 등록 (명칭, 상대팀, 날짜, 장소, 홈/원정)
경기 목록 보기 (날짜순 정렬)
포지션 포메이션 필드 — 11명의 선수를 GK~FW 포지션에 배치 (드래그 없이 배정 버튼으로 추가)
대기 선수 목록 — 추가 배정 가능한 선수 확인 및 선택 배정
경기 상세에서 선수 제거 가능
## 4. 📌 포지션 관리
GK / DF / MF / FW 기본 포지션 제공
포지션별 활동 선수 수 자동 카운트
포지션별 선수 배정 현황
## 5. 🔧 기술적 특징
로컬 스토리지 기반 — 브라우저에 저장되어 서버 없이 실행
반응형 디자인 — 데스크톱/태블릿/모바일 모두 지원
다크 사이드바 — 모던한 UI/UX
토스트 알림 — 작업 완료 피드백
모달 폼 — 선수/경기 등록 및 수정
기본 시드 데이터 — 8명의 선수와 2경기 샘플 포함
선수 통계(득점, 어시스트, 출전 경기) 기록
팀별/리그별 경기 결과 기록
선수단 사진 업로드
CSV/엑셀 데이터 내보내기
다크모드/테마 커스터마이징
